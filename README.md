A comprehensive collection of **Web Technology laboratory experiments and practical assignments** built using **HTML5, CSS3, and JavaScript**.

# 📖 About

This repository contains multiple laboratory experiments completed during my Web Technology course. Each experiment focuses on a different concept, helping me build a strong foundation in frontend development.

The experiments progress from basic HTML structure to CSS styling, responsive layouts, JavaScript programming, DOM manipulation, and browser APIs.

# 🚀 Getting Started

Clone the repository

```bash

```

Open the project


No additional installation is required.
